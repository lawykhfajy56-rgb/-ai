# Cloudy Android project

This repository contains a starter Android project for "كلودي Cloudy" — a floating AI assistant for Android 15.

## Included features
- Floating cloud overlay service
- Arabic-friendly main screen
- Microphone permission handling
- Overlay permission handling
- Simple speech-to-text and text-to-speech integration
- Installable Android app structure

## Project structure
- `app/src/main/java/com/cloudy/ai/MainActivity.kt`
- `app/src/main/java/com/cloudy/ai/FloatingCloudService.kt`
- `app/src/main/res/layout/activity_main.xml`
- `app/src/main/AndroidManifest.xml`

## Requirements
- Android Studio
- JDK 17+
- Android SDK 35

## How to run
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Select a device or emulator.
4. Run the app.
5. Allow microphone and overlay permissions when prompted.

## Notes
This is a functional starter scaffold designed to be expanded into a full AI assistant with a backend or cloud API.
